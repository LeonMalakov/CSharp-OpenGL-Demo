# C# OpenGL Demo

A small 3D application developed using C#, OpenTK, and OpenGL.

**Features:**

- 3D rendering with custom GLSL shaders
- VAO/VBO management and instanced rendering
- OBJ model loading, materials, and textures
- Basic lighting and particle effects
- Camera movement and simple gameplay interactions
